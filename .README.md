# Multi‑Tenant Chatbot – Local Setup (uv + Vite)

This document explains how to run the **backend** (FastAPI) and **frontend** (Vite + React) locally using the [`uv`](https://docs.astral.sh/uv/) Python tool.

---

## 1. Prerequisites

- `Python` 3.10+ installed and on your `PATH`
- `uv` installed (one of):
  - `pip install uv`
  - or follow the official install instructions from Astral
- `Node.js` 18+ (comes with `npm`)

All commands below assume you are in the project root:

```powershell
cd C:\Users\...\itl_chatbot_works
```

---

## 2. Backend Setup (FastAPI + uv)

Backend code lives in `backend/src` and the FastAPI entrypoint is `backend/src/main.py`.

### 2.1 Create a uv virtual environment

From the project root:

```powershell
cd backend

# Create a .venv managed by uv
uv venv .venv
```

You don’t have to activate `.venv` when using `uv run`, but if you want to use `python` directly:

```powershell
.\.venv\Scripts\activate
```

### 2.2 Install backend dependencies

Depending on how your backend dependencies are defined:

- If you have a `pyproject.toml` in `backend`:

```powershell
uv sync
```

- If you have a `requirements.txt` in `backend`:

```powershell
uv pip install -r requirements.txt
```

> Use only one of the above, depending on your project configuration.

### 2.3 Configure environment variables

FastAPI settings are defined in `backend/src/config.py` (Pydantic `Settings`).

Recommended environment variables (via `.env` in `backend` or your shell):

```bash
# Database
DATABASE_URL=postgresql://postgres:Postgres123!@172.23.178.103:32001/chatbot

# General
ENVIRONMENT=development
API_HOST=0.0.0.0
API_PORT=8000

# Optional (for rate limiting)
REDIS_URL=redis://localhost:6379
```

If `DATABASE_URL` is not set, the default in `config.py` is already:

```text
postgresql://postgres:Postgres123!@172.23.178.103:32001/chatbot
```

### 2.4 (Optional) Run database migrations

If you are using Alembic (there is an `alembic.ini` in `backend`):

```powershell
cd backend
uv run alembic upgrade head
```

This applies all migrations to your PostgreSQL database.

### 2.5 Run the backend API with uv

From `backend`:

```powershell
cd backend

# Run FastAPI app (reload in development is handled inside main.py)
uv run python src/main.py
```

The API will be available at:

- `http://localhost:8000/`
- `http://localhost:8000/docs` (Swagger UI)
- `http://localhost:8000/redoc` (ReDoc)

---

## 3. Frontend Setup (Vite + React)

Frontend code lives in the `frontend` folder.

### 3.1 Install Node dependencies

From the project root:

```powershell
cd frontend
npm install
```

This uses `package.json` (Vite + React + TypeScript).

### 3.2 Configure backend URL (optional)

By default, `frontend/constants.ts` has:

```ts
apiUrl: 'http://localhost:8000/api/rag'
```

If your backend runs at a different host or port, update this value to match.

### 3.3 Run the frontend dev server

From `frontend`:

```powershell
npm run dev
```

Vite will start a dev server (by default at `http://localhost:5173`).

---

## 4. Run Full Stack

1. Start backend (new terminal):

   ```powershell
   cd backend
   uv run python src/main.py
   ```

2. Start frontend (another terminal):

   ```powershell
   cd frontend
   npm run dev
   ```

3. Open the browser at the URL shown by Vite (usually `http://localhost:5173`) and use the chatbot UI, which will call the FastAPI backend running on `http://localhost:8000`.
